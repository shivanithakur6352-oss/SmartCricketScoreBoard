
🏏 Smart Cricket Scoreboard

Overview

Smart Cricket Scoreboard is a feature-rich Core Java application that simulates a real-time cricket scoring system. The project is designed to replace manual scorekeeping with an automated, accurate, and user-friendly solution. It enables users to create teams, manage players, record ball-by-ball match events, calculate match statistics, and generate detailed score summaries. The application demonstrates the practical implementation of Core Java concepts while solving a real-world problem.

Key Features

- Live ball-by-ball score updates
- Team and player management
- Automatic calculation of runs, wickets, overs, strike rate, and run rate
- Match summary generation
- File-based data storage for persistent records
- Menu-driven console interface
- Error handling for invalid inputs
- Clean and modular code structure

How to Run

1. Clone the repository.
2. Open it in IntelliJ IDEA, Eclipse, VS Code, or any Java IDE.
3. Compile the project.
4. Run "Main.java".
5. Follow the menu options to create teams, start matches, and update scores.
